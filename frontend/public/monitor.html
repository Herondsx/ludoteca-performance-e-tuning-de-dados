🛰️ Monitor dos Bancos

Persistência poliglota ao vivo

A Ludoteca não guarda tudo num banco só: são três bancos diferentes, e cada um ficou com a parte do sistema cujo formato de dado combina com ele. Esta página consulta as três APIs a cada 3 segundos e mostra o que está gravado em cada banco neste momento.

  • PostgreSQL · relacional Contas, favoritos e visualizações. Precisa de e-mail único, chaves estrangeiras e COUNT/GROUP BY pro ranking.
  • MongoDB · documentos O catálogo de jogos. Cada jogo tem uma “ficha” diferente (expansões, listas de mecânicas, faixa de jogadores aninhada), e documento aceita isso sem migração.
  • Neo4j · grafo As afinidades. “Jogos parecidos” é andar pelas ligações jogo → mecânica/designer → jogo, coisa que no relacional viraria um monte de JOIN.

💡 Teste de independência: rode docker compose stop mongodb e veja só o cartão do MongoDB ficar offline. Depois docker compose start mongodb e ele volta sozinho.

Cada botão chama uma rota de verdade. Os números dos cartões lá embaixo mudam na próxima atualização.
